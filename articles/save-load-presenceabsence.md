# Saving and loading letsR objects

## Overview

Objects generated by `letsR`, including `PresenceAbsence` objects and
the outputs of functions such as `lets.envpam` and `lets.attrpam`, may
contain spatial rasters stored as `SpatRaster` objects from the `terra`
package. Because these objects may reference external data or memory
resources, saving them directly with the base R
[`save()`](https://rdrr.io/r/base/save.html) function may not preserve
their contents correctly.

To ensure reliable serialization, `letsR` provides two functions:
[`lets.save()`](https://brunovilela.github.io/letsR/reference/lets.save.md)
and
[`lets.load()`](https://brunovilela.github.io/letsR/reference/lets.load.md).
These functions work similarly to the base R
[`save()`](https://rdrr.io/r/base/save.html) and
[`load()`](https://rdrr.io/r/base/load.html) functions, but
automatically handle spatial raster components. All `SpatRaster`
elements are prepared for serialization when saving and reconstructed
when loading, preserving the original object structure.

## Saving and loading objects

The same workflow can be applied to different types of `letsR` objects.
For example, a `PresenceAbsence` object can be saved and subsequently
restored as follows:

``` r

library(letsR)

# Load example data
data(PAM)

# Save the PresenceAbsence object
lets.save(PAM, file = "PAM.RData")

# Load the saved object
PAM <- lets.load(file = "PAM.RData")
```

The functions also support objects returned by
[`lets.envpam()`](https://brunovilela.github.io/letsR/reference/lets.envpam.md)
and
[`lets.attrpam()`](https://brunovilela.github.io/letsR/reference/lets.attrpam.md),
without requiring any additional arguments or modifications.

``` r

# Save and load an environmental PAM object
lets.save(envpam, file = "envPAM.RData")
envpam <- lets.load("envPAM.RData")

# Save and load an attribute PAM object
lets.save(pam_att, file = "attrPAM.RData")
pam_att <- lets.load("attrPAM.RData")
```

In all cases, matrix components, spatial rasters, and other object
attributes are preserved, allowing the restored objects to be used
directly in subsequent analyses.
