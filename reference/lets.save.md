# Save a letsR object

Save PresenceAbsence objects and other letsR objects generated by
functions such as
[`lets.envpam`](https://brunovilela.github.io/letsR/reference/lets.envpam.md)
and
[`lets.attrpam`](https://brunovilela.github.io/letsR/reference/lets.attrpam.md).
All SpatRaster components are automatically prepared for serialization,
allowing the complete object to be restored using
[`lets.load`](https://brunovilela.github.io/letsR/reference/lets.load.md).

Supports objects returned by
[`lets.presab`](https://brunovilela.github.io/letsR/reference/lets.presab.md),
[`lets.envpam`](https://brunovilela.github.io/letsR/reference/lets.envpam.md),
and
[`lets.attrpam`](https://brunovilela.github.io/letsR/reference/lets.attrpam.md).

## Usage

``` r
lets.save(pam, ...)
```

## Arguments

- pam:

  A letsR object containing matrices and/or SpatRaster components.

- ...:

  Additional arguments passed to
  [`save`](https://rdrr.io/r/base/save.html).

## Value

Invisibly returns NULL. The object is saved to a file.
